Order Workflow Management System (Manual Control Mode)

มุมมองสิทธิ์ใช้งาน:
ผู้ใช้งาน Role
คำสั่งซื้อทั้งหมด 0
พื้นที่เสี่ยงชายแดน (72 ตำบล) 0
รอตรวจสอบ TamCI / Red Zone 0
ติดตั้งสำเร็จ 0
ยกเลิก / ปฏิเสธ 0
ฝ่ายขาย (Sale) - ดำเนินการคำสั่งซื้อ

1. ลงทะเบียนคำสั่งซื้อใหม่ (Register Order)

* สามารถเลือก/ถ่ายภาพได้สูงสุด 5 ภาพ

ข้อมูลช่วยเหลือการดำเนินงาน:

  • Manual Mode: ยกเลิกระบบรันอัตโนมัติเบื้องหลัง ให้กดปุ่มดำเนินการแต่ละขั้นตอนด้วยตนเอง
  • TamCI: ตรวจสอบพิกัดพื้นที่
  • SmartMap: ตรวจสอบพิกัดความถูกต้องบนแผนที่

2. ดำเนินการโดยทีมช่างสนาม (Technician Workstation)

กดรับงาน ตรวจสอบธงพื้นที่ และบันทึกผลการติดตั้งด้วยตนเอง

3. การตรวจสอบโดยทีมสนับสนุน (BBIM Verification)

ตรวจสอบคำขอ TamCI, การขายข้ามโซน (Cross Zone) และอนุมัติ/ปฏิเสธพื้นที่ Red Zone ด้วยตนเอง

Master Command & Admin Approval Panel

ผู้ดูแลระบบ (Admin) สามารถอนุมัติสิทธิ์ให้ Admin ผู้สมัครใหม่ และดูภาพรวมระบบได้ที่นี่
