ฝ่ายขาย (Sale) - ดำเนินการคำสั่งซื้อ

1. ลงทะเบียนคำสั่งซื้อใหม่ (Register Order)

เครื่องมือสนับสนุนการทำงาน (Need Support System):

  • FBB Workflow: ตั้งค่า Auto Remark สำหรับ 72 ตำบลเสี่ยง
  • TamCI: ส่งคำขอตรวจสอบพิกัดพื้นที่
  • SmartMap: ตรวจสอบพิกัดความถูกต้องบนแผนที่

2. การประมวลผลระบบอัตโนมัติ (System Automated Process)

เลือก Order เพื่อจำลองการประมวลผลระบบอัตโนมัติ (Check Border Area 72 Sub District -> Add Flag -> Auto Remark -> FBSS Appointment -> Dispatch)

3. ดำเนินการโดยทีมช่างสนาม (Technician Workstation)

กดรับงาน ตรวจสอบธงพื้นที่ชายแดน และบันทึกผลการติดตั้ง

4. การตรวจสอบโดยทีมสนับสนุน (BBIM Verification)

ตรวจสอบคำขอ TamCI, การขายข้ามโซน (Cross Zone) และอนุมัติ/ปฏิเสธพื้นที่ Red Zone
